Installer sur Android

Télécharger l'application
  1. Touchez Télécharger. Si le navigateur demande de confirmer, choisissez Télécharger quand même.
  2. Ouvrez le fichier téléchargé (dans les notifications ou le dossier « Téléchargements »).
  3. Si le téléphone le demande, touchez Paramètres puis autorisez l'installation depuis cette source.
  4. Touchez Installer, puis Ouvrir.
Gratuit pendant 30 jours. Aucune carte bancaire demandée.
